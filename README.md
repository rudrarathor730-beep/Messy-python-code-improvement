## About the Project
This project demonstrates how Cursor AI can help analyze and improve messy Python code using clear instructions and custom coding rules.

## Objectives
- Understand existing Python code without modifying it.
- Improve code readability and organization.
- Use descriptive variable and function names.
- Follow consistent Python coding standards.
- Explore AI-assisted code improvement.

## Project Files
- `messy_py.py` — Python program used for code improvement.
- `improved_py.py` — Improved and refactored Python program.
- `rules/python-standard.mdc` — Custom coding rules for Cursor AI.
- `audit.md` — Code improvement audit notes.

## Tools Used
- Python
- Cursor AI
- Git
- GitHub

## Workflow
1. Open and analyze the original Python program.
2. Ask Cursor AI to explain the code without making changes.
3. Use specific prompts to improve the code while preserving its intended output.
4. Apply custom coding rules.
5. Track and publish project files using Git and GitHub.
